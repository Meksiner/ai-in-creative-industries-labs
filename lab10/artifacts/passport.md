## 9. Паспорт эксперимента

**Лабораторная работа № 10:** «Сравнительное исследование моделей text-to-image».

**Вариант:** 22.

**Дата проведения:** 13.11.2026.

**Цель эксперимента:** сравнительная оценка качества соответствия текстовому описанию и вычислительных затрат двух моделей генерации изображений.

### 1. Среда выполнения

* Платформа: Engee.

* Основной язык среды: Julia.

* Язык экспериментального кода: Python.

* Библиотека эксперимента: `lab10_lib.py`.

* PyTorch: 2.4.1 (целевая версия по методичке).

* diffusers: 0.32.2 (установленная по инструкции версия).

* transformers: 4.57.x (целевая версия по методичке; точный номер не зафиксирован).

* Количество потоков PyTorch: 4 (настройка библиотеки).

### 2. Исследуемые модели

**Модель A — LCM Dreamshaper v7**

* Количество шагов генерации: 4.

* Guidance scale: 8.0.

* Разрешение: 512 × 512 пикселей.

* Лицензия по методичке: MIT.

**Модель B — bk-sdm-tiny**

* Количество шагов генерации: 10.

* Guidance scale: 7.5.

* Разрешение: 512 × 512 пикселей.

* Лицензия по методичке: CreativeML OpenRAIL-M.

Точные идентификаторы ревизий моделей при запуске не зафиксированы.

### 3. Входные данные

**Бриф № 4:** визуальный материал для лекций по экологии — лесной полог, вид сверху, многослойные зелёные формы, мягкий утренний свет.

**Seed:** 101, 102, 103, 104, 105.

**Количество изображений:** 10 (по 5 для каждой модели).

**Метрики:** clip\_brief, clip\_text, edge, contrast, seconds.

### 5. Визуальная оценка

Выполнено сравнение пяти пар изображений. По субъективной оценке LCM Dreamshaper v7 получила три предпочтения, bk-sdm-tiny — два.

Оценивались соответствие брифу, характер освещения, цветовая палитра, многослойность лесного полога и композиция.

### 6. Ограничения эксперимента

Числовые допуски практической значимости не были установлены до начала эксперимента. Ключ слепого сравнения был открыт до завершения визуальной оценки, поэтому процедура не соответствует требованиям строгого ослепления.

Полученные результаты применимы к заданному брифу, конфигурациям моделей и пяти исследованным значениям seed. Обобщение результатов на другие задачи генерации изображений не выполнялось.

### 7. Артефакты эксперимента

* `lab10_lib.py` — библиотека эксперимента.

* `variant22.py` — скрипт запуска.

* `v22/lcm_s101.jpg` — `v22/lcm_s105.jpg` — изображения модели A.

* `v22/bk_s101.jpg` — `v22/bk_s105.jpg` — изображения модели B.

* `v22/blind_101.png` — `v22/blind_105.png` — листы сравнения.

* `v22/blind_key.json` — ключ соответствия моделей и расположения изображений.

* Вывод `variant_summary(22)` — численные результаты эксперимента.
