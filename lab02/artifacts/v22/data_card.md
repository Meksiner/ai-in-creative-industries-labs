# Паспорт набора данных — ЛР №2, вариант 22

**Сценарий использования:** внутренний прототип без публикации.

## 1. Motivation (мотивация)

Набор данных создан для учебного исследования вопросов лицензирования, происхождения материалов и управления рисками при разработке внутреннего прототипа с применением технологий искусственного интеллекта.

Цель набора — проверить возможность использования материалов с различными лицензиями, выявить нарушения и определить необходимые действия для их устранения.

Набор предназначен для учебной работы студента. Его использование в коммерческих продуктах или публичных проектах не предусмотрено.

## 2. Composition (состав)

Набор содержит 12 синтетических объектов:

- аудиофайлы — 4;
- текстовые файлы — 4;
- изображения — 4.

Распределение лицензий:

| Лицензия | Количество |
|---|---:|
| MIT | 3 |
| CC0-1.0 | 2 |
| Apache-2.0 | 2 |
| CC-BY-4.0 | 1 |
| CC BY 4 | 1 |
| free-to-use | 1 |
| Public domain | 1 |
| Не указана | 1 |

Персональные данные отсутствуют.

Для шести объектов лицензии предусматривают указание авторства.

По результатам автоматического аудита выявлено 4 ошибки и 1 предупреждение.

## 3. Collection Process (процесс сбора)

Набор сформирован автоматически с помощью учебного скрипта `lab02_make_variant.py` для варианта №22.

Все объекты и сведения об их правообладателях являются синтетическими. Реальные изображения, аудиозаписи и текстовые материалы не собирались.

В манифесте указаны условные источники с доменом `example.org`.

Даты получения объектов находятся в диапазоне от 03.02.2026 до 24.08.2026. Эти даты являются частью синтетических метаданных, а не свидетельством фактического скачивания материалов.

Персональные данные в наборе отсутствуют, поэтому получение согласий на их обработку не требовалось.

## 4. Preprocessing/cleaning/labeling (обработка и разметка)

После генерации набора выполнен автоматический аудит файла `manifest.csv` с использованием скрипта `lab02_audit.py`.

Проверялись наличие лицензии, корректность её идентификатора, сведения о правообладателях и другие признаки возможных нарушений.

Выявлены следующие проблемы и приняты решения:

| Объект | Проблема | Решение |
|---|---|---|
| item06 | Нестандартная запись `CC BY 4` | Запросить подтверждение лицензии CC-BY-4.0 |
| item07 | Неопределённое обозначение `free-to-use` | Исключить до уточнения условий |
| item09 | Не указан правообладатель | Запросить сведения о правообладателе |
| item10 | Неопределённый статус `Public domain` | Запросить подтверждение правового статуса |
| item11 | Лицензия отсутствует | Исключить до получения разрешения |

До подтверждения прав проблемные объекты не допускаются к использованию в прототипе.

Исходный манифест сохраняется для воспроизводимости аудита. Решения документируются отдельно; фактическая замена материалов и исправление лицензий не выполнялись.

## 5. Uses (использование)

Предполагаемое использование — внутренний некоммерческий прототип без публикации и передачи набора третьим лицам.

Создание производных материалов допускается политикой сценария, но только при соблюдении условий лицензий исходных объектов.

Набор не предназначен для коммерческого распространения, публичного размещения, обучения реальных производственных моделей или использования в качестве подтверждённой коллекции лицензированных материалов.

Использование объектов с неподтверждёнными правами ограничивается до разрешения выявленных проблем.

## 6. Distribution (распространение)

Публикация и передача набора третьим лицам не предполагаются.

Материалы предназначены для локальной учебной проверки и документирования результатов аудита.

Если в дальнейшем возникнет необходимость распространения набора, потребуется повторная проверка лицензий, правообладателей и условий использования каждого объекта.

Публикация паспорта или отчёта об аудите не означает автоматического разрешения на распространение исходных материалов.

## 7. Maintenance (сопровождение)

За ведение учебного набора, фиксацию результатов аудита и документирование решений отвечает студент, выполняющий лабораторную работу.

При обнаружении ошибки в лицензии, происхождении или сведениях о правообладателе соответствующий объект должен быть помечен как требующий проверки и исключён из дальнейшего использования до устранения проблемы.

Запросы об исправлении или удалении объектов рассматриваются ответственным за набор. При необходимости уточнения правовых условий требуется обращение к правообладателю или специалисту по интеллектуальной собственности.

Изменения в составе набора необходимо фиксировать в журнале лабораторной работы.

## Итоговое заключение

Исходный набор содержит 12 синтетических объектов. Автоматический аудит выявил 4 ошибки и 1 предупреждение.

Для каждой находки определено решение. До подтверждения прав проблемные объекты не должны использоваться в прототипе.

Набор пригоден для учебного анализа лицензий и происхождения данных. Его использование в качестве набора материалов для прототипа возможно только с учётом выявленных ограничений.

Автоматическая проверка основана на сведениях манифеста, не подтверждает достоверность заявленных лицензий и не является юридической консультацией.
