## 5. Гипотеза и допуск

### 5.1. Гипотеза

До проведения основного эксперимента сформулирована следующая гипотеза:

При изменении типа вычислений с `float16` на `float32` изображения будут различаться даже при одинаковом seed.

Предполагается, что существенная часть различий связана с особенностями формирования начального шума. Если подать в оба режима одинаковый начальный шум, различия должны уменьшиться.

### 5.2. Практический допуск

До выполнения сравнения установлен порог **PSNR = 40 дБ**.

| Критерий | Интерпретация |
|---|---|
| Полное совпадение пикселей | Изображения идентичны |
| PSNR ≥ 40 дБ | Изображения практически совпадают |
| PSNR < 40 дБ | Изображения различаются |

Для оценки результатов используются контрольные суммы SHA-256, проверка совпадения пикселей, максимальное абсолютное различие и метрика PSNR.

Контрольная сумма SHA-256 позволяет проверять идентичность сохранённых файлов. PSNR характеризует численное сходство изображений, но не их художественное качество.

## 7. Сравнение условий A и B

Для индивидуального варианта № 22 выполнено сравнение вычислений `float16` и `float32` с одинаковым seed 1022.

Изображения A и B получены в одном сеансе с помощью функции `L.make_pair()` учебной библиотеки.

### 7.1. Результаты основного сравнения

| Показатель | Результат |
|---|---|
| SHA-256 A (`float16`) | `4a0b8635c62a395b68f8150ff3049c56af43e4e2bf8e206d730570837993d925` |
| SHA-256 B (`float32`) | `83401c691122b3b3178cbb9b3e2f2516ab8da406510cd9327bd5d53930dbd081` |
| Совпадение пикселей | Нет |
| Максимальное абсолютное различие | 170 |
| PSNR | 15,8594 дБ |
| Практический допуск | 40 дБ |
| Вердикт | `different` |

Контрольные суммы изображений A и B различаются.

Значение PSNR 15,8594 дБ ниже установленного порога 40 дБ. Следовательно, изображения различаются по принятому критерию.

### 7.2. Проверка влияния начального шума

Для исследования причины различий проведён дополнительный эксперимент с использованием функции `generate_fixed_noise()`.

В обоих режимах использовался одинаковый исходный шум, сформированный в `float32` и приведённый к соответствующему вычислительному типу.

| Условия сравнения | PSNR | Оценка |
|---|---:|---|
| Обычная генерация с одинаковым seed | 15,8594 дБ | Различаются |
| Генерация с одинаковым начальным шумом | 48,5157 дБ | Практически совпадают |

При фиксации начального шума PSNR увеличился примерно на **32,66 дБ**.

Полученное значение 48,5157 дБ превышает установленный допуск 40 дБ.

Результат согласуется с гипотезой о том, что существенная часть первоначального различия связана с формированием начального шума, а не только с точностью вычислений.

При этом изображения не объявляются побитово идентичными: установлен лишь факт практического совпадения по метрике PSNR.

### 7.3. Визуальная оценка

Оба изображения представляют лесной полог при взгляде сверху. В композиции различимы зелёные кроны деревьев, неоднородные участки растительности и более тёмные промежутки между ними.

В обоих результатах сохраняется многослойная структура лесного полога и визуальное ощущение глубины за счёт различий в размерах, оттенках и расположении крон.

Несмотря на значительные численные различия между изображениями A и B, общий сюжет и основные требования брифа сохраняются.

Изображения не содержат текста и людей.

Результаты представляют собой стилизацию, поэтому по ним нельзя делать выводы о реальном состоянии леса, видовом составе растений или экологических характеристиках территории.

## 8. Намеренно введённая ошибка

### 8.1. Описание ошибки

Для проверки воспроизводимости один объект `torch.Generator`, инициализированный с seed 1022, использовался для двух последовательных запусков модели.

```python
g = torch.Generator(device="cpu").manual_seed(1022)
```

После первого вызова внутреннее состояние генератора изменилось. Второй вызов использовал уже изменённое состояние, поэтому был сформирован другой начальный шум.

### 8.2. Результаты ошибки

**SHA-256 первого запуска:**

```text
4a0b8635c62a395b68f8150ff3049c56af43e4e2bf8e206d730570837993d925
```

**SHA-256 второго запуска:**

```text
2900b3f1c8037832dbc4453c6c9e921dd47dcfe36319dd2b54d4af83a244ad95
```

| Показатель | Результат |
|---|---|
| Совпадение SHA-256 | Нет |
| PSNR | 15,5546 дБ |
| Результат | Изображения различаются |

Таким образом, повторное использование одного генератора без восстановления его начального состояния нарушило воспроизводимость результата.

### 8.3. Исправление ошибки

Для исправления перед каждым запуском создавался новый генератор с одинаковым seed.

В учебной библиотеке этот подход реализован функцией `L.generate()`.

После исправления получены следующие результаты:

| Показатель | Результат |
|---|---|
| SHA-256 первого запуска | `4a0b8635c62a395b68f8150ff3049c56af43e4e2bf8e206d730570837993d925` |
| SHA-256 второго запуска | `4a0b8635c62a395b68f8150ff3049c56af43e4e2bf8e206d730570837993d925` |
| Совпадение SHA-256 | Да |
| PSNR | +∞ дБ |
| Совпадение пикселей | Да |

Исправление обеспечило полную воспроизводимость изображений в пределах исследованного сеанса и вычислительной среды.
