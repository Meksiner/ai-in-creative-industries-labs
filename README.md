# Лабораторные работы

Репозиторий для хранения лабораторных работ, выполненных в рамках обучения в магистратуре.

Здесь собраны исходный код, результаты экспериментов, отчёты и дополнительные материалы по учебным дисциплинам.

## Структура репозитория

```text
.
├── lab01/
│   ├── artifacts/
│   │   ├── no_seed_1/
│   │   ├── no_seed_2/
│   │   ├── run1/
│   │   ├── run2/
│   │   ├── run3/
│   │   ├── test/
│   │   └── v22/
│   │       └── artifacts/
│   ├── config/
│   ├── demo_journal/
│   │   └── variant01/
│   │       └── artifacts/
│   ├── reports/
│   └── src/
├── lab02/
│   ├── artifacts/
│   │   └── v22/
│   ├── demo_journal/
│   │   └── variant01/
│   ├── reports/
│   └── src/
├── lab03/
│   ├── demo_journal/
│   └── src/
└── README.md
```

Структура лабораторных работ различается в зависимости от требований задания.

- **`src/`** — исходный код и скрипты.
- **`artifacts/`** — результаты выполнения экспериментов.
- **`reports/`** — отчёты по лабораторным работам.
- **`config/`** — конфигурационные файлы.
- **`demo_journal/`** — материалы демонстрационных экспериментов.
- **`v22/`** — материалы индивидуального варианта №22.
```

Структура отдельных лабораторных работ может отличаться в зависимости от требований задания.
